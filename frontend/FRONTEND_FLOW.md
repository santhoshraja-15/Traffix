# TRAFFIX Frontend Flow

This is the master behavioral flow document.

## MASTER FLOW

```
START
  ↓
APPLICATION LOAD
  ↓
CONNECT BACKEND
  ↓
CONNECT WEBSOCKET
  ↓
LOAD SUMO CITY
  ↓
DISPLAY LIVE TRAFFIC
  ↓
USER ENTERS FROM
  ↓
USER ENTERS DESTINATION
  ↓
VALIDATE LOCATIONS
  ↓
MAP TO SUMO NODES
  ↓
CALCULATE SHORTEST PATH
  ↓
DISPLAY SHORTEST ROUTE
  ↓
SHOW "SHORTEST ROUTE FOUND"
  ↓
LOADING OPTIMAL ROUTES
  ↓
ANALYZE TRAFFIC
  ↓
XGBOOST PREDICTION
  ↓
NETWORKX ROUTING
  ↓
ROUTE SCORING
  ↓
TOP 3 ROUTES
  ↓
SELECT RECOMMENDED ROUTE
  ↓
START NAVIGATION
  ↓
LIVE TRAFFIC UPDATES
  ↓
TRACK USER
  ↓
UPDATE ETA
  ↓
UPDATE DISTANCE
  ↓
UPDATE NEXT TURN
  ↓
REACH INTERSECTION
  ↓
RECALCULATE
  ↓
COMPARE TOP ROUTES
  ↓
CONTINUE
  ↓
DESTINATION
  ↓
TRIP COMPLETE
```

---

## ACCIDENT FLOW

```
FEATURES
  ↓
ACCIDENT
  ↓
CHOOSE ON MAP
  ↓
SELECT ROAD
  ↓
SIMULATE ACCIDENT
  ↓
ACCIDENT MARKER
  ↓
RIPPLE EFFECT
  ↓
ACCIDENT ZONE
  ↓
TRAFFIC RISK INCREASE
  ↓
MESSAGE ALERT
  ↓
AFFECTED ROUTES IDENTIFIED
  ↓
REROUTING
  ↓
TOP ROUTES UPDATED
  ↓
NAVIGATION CONTINUES
```

---

## AMBULANCE FLOW

```
ACCIDENT
  ↓
FIND NEAREST AMBULANCE
  ↓
COMPARE AMBULANCES
  ↓
SELECT BEST AMBULANCE
  ↓
ASSIGN
  ↓
DISPLAY ASSIGNMENT
  ↓
START RESCUE
  ↓
CALCULATE EMERGENCY ROUTE
  ↓
AMBULANCE MOVES
  ↓
TRAFFIC YIELDS
  ↓
ACCIDENT LOCATION
  ↓
RESCUE WAIT
  ↓
FIND NEAREST HOSPITAL
  ↓
CALCULATE HOSPITAL ROUTE
  ↓
AMBULANCE MOVES
  ↓
HOSPITAL
  ↓
RESCUE SUCCESSFUL
```

---

## ROUTE UPDATE FLOW

```
CURRENT LOCATION
  ↓
CURRENT ROAD
  ↓
NEXT INTERSECTION
  ↓
FETCH TRAFFIC STATE
  ↓
CALCULATE ROUTES
  ↓
SCORE ROUTES
  ↓
TOP 3
  ↓
SELECT BEST
  ↓
COMPARE CURRENT ROUTE
  ↓
IF SIGNIFICANTLY BETTER
    ↓
  REROUTE
  ↓
UPDATE UI
```

---

## MODE FLOW

```
SIMULATION
  ↓
SUMO/TraCI STATE

REAL-TIME
  ↓
LIVE DATA ADAPTER
```

Both modes must use the same frontend interface.

Only the data source changes.
